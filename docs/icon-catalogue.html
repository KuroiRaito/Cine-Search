Icon Catalogue

There is no icon library in this project. Every icon on every screen is a Unicode text character borrowed from whatever block had something roughly the right shape — and that is the whole reason they look mismatched. Pick a set at the bottom and I will do the work.

01

Why they look wrong

Twenty different glyphs, drawn from five unrelated Unicode blocks — punctuation, geometric shapes, dingbats, miscellaneous symbols and technical. Nobody designed them to sit together, because nobody designed them together at all.

An 8.6× spread in painted size, and 48px of vertical drift — at one font-size. Your search icon paints 44px where Discover paints 86px, which is exactly the “search icon is very small” you reported. ⌃ and ⌄ sit 48px apart vertically, which is why anything using them looks off its line. This cannot be fixed by nudging font sizes: it would take twenty per-glyph sizes and twenty offsets, and they would all break the moment a font falls back differently on someone else’s machine.
There is also a correctness problem. ⌕ is telephone recorder, not a magnifying glass. ◍ is circle with vertical fill, not a person. A screen reader gets nothing useful from either, and neither will ever be found by someone looking for the icon they expect.

03

At the three sizes the system defines

--icon-16, --icon-20 and --icon-24 already exist in foundations.html §07. Shown inside a 44px control box so you can see the optical padding as well as the glyph.

16px
20px
24px
16px is where sets separate. A 2px stroke on a 24px grid becomes a 1.33px stroke at 16px, which on a non-retina screen lands between pixels and goes soft. Heroicons ships a purpose-drawn 16px set; Lucide and Tabler stay on one grid and want their stroke lifting to about 2.25 at small sizes. Phosphor being a fill set sidesteps the problem entirely, and pays for it by feeling heavier.

05

What I would pick, and why

Lucide
my recommendation
  • 24px grid, 2px stroke — matches --icon-24 and the 1px border / 2px focus weights already in the system
  • 1,500+ icons, ISC licence, no attribution needed
  • Tree-shakes: only the ~33 used ship, roughly 4 KB gzipped
  • lucide-react-native exists — the native milestone is already delivery order three
  • Stroke width is a prop, so 16px icons can be lifted to 2.25 without a second set
  • Neutral. It will not date the product.
Phosphor
if you want character
  • Six weights including duotone — genuinely interesting for the six watch states
  • 9,000+ icons, MIT
  • Rounder, friendlier, more opinionated
  • Regular weight is a fill set, which reads heavier on a dark ground than the rest of this UI
  • 256px viewBox, so it does not share a grid with the 24px system
Heroicons
tightest quality, smallest set
  • Purpose-drawn at 24, 20 and 16 — the only one that solves small sizes properly
  • MIT, by the Tailwind team
  • Only ~300 icons; no compass, so Discover needs a different metaphor
  • 1.5px stroke is lighter than this UI’s other lines
Tabler
largest outline set
  • 5,700+ icons, MIT, 24px grid, 2px stroke
  • Closest alternative to Lucide on the numbers
  • Slightly more detailed drawings, which get busy at 16px
  • Smaller React ecosystem than Lucide
One thing is not a choice: an icon is never the only signal. Whatever set you pick, every icon-only control keeps an aria-label that reads as speech — “Back”, not “chevron-left” — and the six watch states keep their text labels. That rule is already in the foundations and does not change.
06

What happens once you pick

Nothing has changed yet. On your word:

StepWhat
1Add --icon-16/20/24 as real boxes to foundations.html §07 — the tokens exist, nothing obeys them yet.
2One <Icon> component in shared/ui: fixed square box, currentColor, size from the token, aria-hidden unless given a label.
3Replace all twenty glyphs. Entry and profile first, since both are freshly designed.
4A verify rule rejecting a bare Unicode glyph used as an icon in src/ — the same way token-scale stops raw pixels coming back.
5Redraw the icons in the design documents so they match what ships.
Step 4 is the one that makes it stick. Without it, the next person needing an icon in a hurry types a character that looks about right, and in six months there are twenty again.
